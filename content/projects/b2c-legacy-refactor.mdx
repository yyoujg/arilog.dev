## 문제

날짜 상태가 여러 컴포넌트에 분산돼 있고 서로 동기화되지 않아 중복 코드와 props drilling이 누적됐다. 번역은 개발자가 건마다 수기로 JSON에 반영해야 했다.

## 해결

- 분산된 날짜 상태를 Recoil 단일 모듈(29 atom/selector)로 점진 이관해 중앙화
- Google Sheet + Sheets API·App Script로 번역 자동화 파이프라인 구축
- 동시 다발 401을 인터셉터 큐로 직렬화해 리프레시 1회 후 일괄 재시도하도록 개선
- iOS·Android 웹뷰와 토큰·로그인 양방향 동기화 브릿지 구현
- hydration mismatch를 mounted state 가드로 해결

## 효과

- 중복 코드 1,854줄 삭제, props drilling 제거
- 번역 반영 병목 제거 (개발자 수기 반영 → 운영팀이 시트에서 직접 반영)
